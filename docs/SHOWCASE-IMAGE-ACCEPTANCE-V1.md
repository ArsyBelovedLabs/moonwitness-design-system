# Showcase Image Acceptance v1

A generated or curated image is accepted as a golden page reference only when all are true:

1. Exactly one authorized screen is represented.
2. Required component-system and UX-flow gates are cleared.
3. Navigation, terminology, metrics, data state and actions come from authorized product contracts/implementation.
4. Geometry and typography do not redefine canonical component masters.
5. Desktop/mobile behavior is known and consistent.
6. Accessibility/status meaning does not rely on color alone.
7. The image is compared with the canonical Figma master and actual application implementation.

Composite presentation boards are useful for review but are not sufficient as sole page-level golden evidence.

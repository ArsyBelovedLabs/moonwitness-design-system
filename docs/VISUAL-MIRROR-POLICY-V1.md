# Visual Mirror Policy v1

Status: ACTIVE / ISSUE #15

`moonwitness-design-system` is a public showcase/compatibility mirror only.

## Rules
- Canonical reusable production UI owner: `ArsyBelovedLabs/moonwitness-frontend-platform`.
- Canonical icon geometry source: `moonwitness-frontend-platform/icons/geometry.json`.
- This repository must not fork reusable component or icon geometry.
- Showcase boards and generated images are downstream review/reference artifacts.
- Any screen marked NEED_REWORK or NOT_GENERATED in the Blueprint screen matrix must not be presented as canonical implementation evidence.
- Images cannot create routes, metrics, capabilities, states, or architecture.
- Application navigation remains application-owned.
